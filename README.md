# チネチッタ 購入履歴コメント

チネチッタ CINE CLUB の購入履歴ページ（`member.cinecitta.co.jp/purchase/history`）に、映画・スクリーン・座席へのコメントを記録できる Chrome 拡張です。

## 機能

- 購入履歴の各アイテムに **コメントパネル** を追加
- 記録できる内容:
  - **映画の総合評価** ★1〜5 + 自由テキスト
  - **スクリーン・座席の評価**（座席の快適さ / 音質 / 映像品質）★1〜5 + 自由テキスト
- ポップアップで **スクリーン×座席の平均評価を統計表示**
- データの **JSON エクスポート / インポート**（バックアップ・移行用）

## インストール

1. `chrome://extensions` を開く
2. 右上「デベロッパーモード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（`cinecitta_chrome_extensions/`）を選択

## 使い方

1. チネチッタ CINE CLUB にログインし、**購入履歴ページ**を開く
2. 各映画の下に「💬 コメントを追加する」ボタンが表示される
3. クリックして展開 → 評価・コメントを入力 → **保存する**
4. 拡張アイコン（ツールバー）をクリックするとポップアップで統計を確認できる

## データの取り扱い

### 保存先

- **Chrome のローカルストレージ**（`chrome.storage.local`）に保存されます
- データはこの PC・このブラウザプロファイルにのみ存在し、**外部サーバーには一切送信されません**
- チネチッタ公式 API には接触しません

### データ形式

```json
{
  "version": 1,
  "records": {
    "<レコードID>": {
      "movieTitle": "映画タイトル",
      "viewingDate": "2026/5/9(土) 12:15",
      "screen": "CINE8",
      "seat": "P-19",
      "movie": {
        "rating": 4,
        "comment": "感想テキスト"
      },
      "screenSeat": {
        "seatComfort": 3,
        "soundQuality": 5,
        "imageQuality": 4,
        "comment": "スクリーンへのメモ"
      },
      "updatedAt": "2026-05-09T12:00:00.000Z"
    }
  }
}
```

### エクスポート / インポート

- ポップアップ →「⚙️ データ管理」タブ
- **エクスポート**: 全データを `.json` ファイルとしてダウンロード
- **インポート**: JSON ファイルを選択すると既存データとマージされます（同一レコードは上書き）
- 別の PC や Chrome プロファイルへの移行にも使えます

### データの削除

- 「⚙️ データ管理」→「🗑️ 全データを削除」で全件削除できます
- Chrome の拡張機能をアンインストールすると、ストレージも削除されます（ブラウザの仕様）

### 容量

`chrome.storage.local` の上限は通常 **10 MB**（デフォルト 5 MB）です。テキストと数値のみの保存のため、数千件のレコードでも問題ありません。

## ファイル構成

```
cinecitta_chrome_extensions/
├── manifest.json      Chrome 拡張の設定
├── content.js         購入履歴ページへの注入スクリプト
├── content.css        コメントパネルのスタイル
├── icons/             拡張アイコン (16 / 48 / 128 px)
└── popup/
    ├── popup.html     ポップアップ UI
    ├── popup.js       統計・データ管理ロジック
    └── popup.css      ポップアップスタイル
```
